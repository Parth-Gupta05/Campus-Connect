If vague (e.g., *\"Generate a survey on jobs\"*), it pauses and returns clarifying questions to narrow demographic scope.\n2. **Context Collector Agent (`context_collector_agent`):** Connects directly to the **MoSPI Model Context Protocol (MCP)** server.    IVR->>AI: POST /speech/stt-twilio-sarvam { url: RecordingUrl }\n    Note over AI: Sarvam Regional STT transcription\n    AI-->>IVR: Returns transcribed text\n    \n    Note over IVR: Option Match containing demographic targets, response arrays, current question indexes, retries, and timestamps.\n* **Keep-Alive Pause:** When Twilio uploads a recording to `/webhook/answer`, transcription takes 2–4 seconds. The service immediately returns a TwiML instruction playing `please_wait.mp3` with a `<Pause>` to prevent the call from hanging up.\n* **Fuzzy MCQ Option Matcher:** The transcription is matched against the localized options. If the user says *\"Option one\"* or *\"Rural area\"*, the system matches it to the respective option ID. If no match is found, it updates the live call to prompt the user again.\n* **Premature Hangup Handler:** The webhook endpoint `/webhook/status` tracks call status. If the citizen hangs up mid-survey, the system submits the partial response to the database so that paradata is preserved.\n* **Audio Proxy Header Correction:** Twilio requires strict audio headers. The `/api/survey/proxy-audio` endpoint streams `.wav` files from the AI service's MinIO storage directly to the Twilio line.\n\n---\n\n## 💬 3. Project with [billing enabled](https://cloud.google.com/billing/docs/how-to/enable-disable).\n    - **APIs Enabled:**\n        - `Vertex AI API`\n        - `Cloud Text-to-Speech API`\n    - However, for consistency with the Docker setup, it's good practice to have it defined.\n\n    Your `.env` file should look like this (replace placeholders with your actual keys):\n    ```env\n    PORT=5000\n    GEMINI_API_KEY=\"YOUR_GEMINI_API_KEY_HERE\"\n    # Optional: Only needed if you're not using gcloud auth application-default login locally\n    # For Docker deployment, this is CRITICAL.\n    GOOGLE_APPLICATION_CREDENTIALS_BASE64=\"YOUR_BASE64_ENCODED_SERVICE_ACCOUNT_JSON_HERE\"\n    ```\n    You can also create a `.env.example` file to guide others:\n    ```env\n    PORT=5000\n    GEMINI_API_KEY=\"YOUR_GEMINI_API_KEY_HERE\"\n    GOOGLE_APPLICATION_CREDENTIALS_BASE64=\"BASE64_ENCODED_GCP_SERVICE_ACCOUNT_KEY_JSON\"\n    ```\n\n3.  **Install dependencies:**\n    ```bash\n    npm install\n    ```\n\n4.  **Run the development server:**\n    To run in development mode with `nodemon` (auto-restarts on file changes):\n    ```bash\n    npm run dev\n    ```\n    To run in production mode:\n    ```bash\n    npm start\n    ```\n    The API will start on `http://localhost:5000` (or your specified `PORT`).\n\n## ⚙️ Environment Variables\n\nThe backend uses the following environment variables:\n\n-   `PORT`: The port on which the Express server will listen. How may I assist you today?\"}\n      ],\n      \"newMessage\": \"Tell me about Diwali.\"\n    }\n    ```\n    - `chats`: An array of previous messages in the conversation, following the `{ \"role\": \"user\" | \"model\", \"content\": \"string\" }` format.\n    - `newMessage`: The latest user query.\n-   **Success Response (JSON):**\n    ```json\n    {\n    \"text\": \"Namaste! Diwali, our Festival of Lights, is a joyous celebration that signifies the triumph of light over darkness, good over evil, and knowledge over ignorance. It's a time when homes are adorned with diyas and colorful decorations, families come together, and prayers are offered to deities like Lakshmi, the goddess of prosperity, and Ganesha, the remover of obstacles.\\n\\nDiwali's roots lie deep in Sanatan Dharma, with various stories and regional traditions associated with it. In some regions, it marks the return of Lord Rama to Ayodhya after his victory over Ravana, while in others, it celebrates Krishna's defeat of the demon Narakasura.\\n\\nThe festival typically spans five days, each with its own significance and rituals. From Dhanteras, which focuses on wealth and prosperity, to Bhai Dooj, which celebrates the bond between brothers and sisters, Diwali is a time of immense cultural and spiritual significance.\\n\\nAnd did you know, AI is playing a role in keeping these traditions alive? Digital archives help preserve ancient rituals, ensuring they're passed down accurately to future generations. It's a beautiful example of \\\"Virasat se Vikas\\\" – development rooted in heritage.\\n\\nWhat aspects of Diwali resonate most with you?\\n\"\n}\n    ```\n-   **Error Response (JSON):**\n    ```json\n    {\n      \"error\": \"Failed to generate response\",\n      \"details\": \"Error message details\"\n    }\n    ```\n-   **Example (cURL):**\n    ```bash\n    curl -X POST http://localhost:5000/api/text \\\n    -H \"Content-Type: application/json\" \\\n    -d '{ \"chats\": [], \"newMessage\": \"What is the importance of Yoga?\" }'\n    ```\n\n### 3. `/api/voice`\n-   **Method:** `POST`\n-   **Description:** Generates a text response from Gemini and then converts it to speech (MP3) using Google Cloud Text-to-Speech.\n-   **Request Body (JSON):**\n    ```json\n    {\n      \"chats\": [\n        {\"role\": \"user\", \"content\": \"Hello Avi!\"}\n      ],\n      \"newMessage\": \"Tell me about Indian classical music.\",\n      \"languageCode\": \"en-IN\"\n    }\n    ```\n    - `chats`: (Same as `/api/text`)\n    - `newMessage`: (Same as `/api/text`)\n    - `languageCode`: The BCP-47 language code for TTS (e.g., `en-IN`, `hi-IN`, `bn-IN`, `mr-IN`, etc.). Defaults to `en-US`.\n-   **Success Response (JSON):**\n    ```json\n    {\n      \"text\": \"Namaste! It's wonderful to delve into the world of Indian classical music with you...\",\n      \"audioContent\": \"BASE64_ENCODED_MP3_AUDIO\"\n    }\n    ```\n-   **Error Response (JSON):**\n    ```json\n    {\n      \"error\": \"Failed to generate voice response\",\n      \"details\": \"Error message details\"\n    }\n    ```\n-   **Example (cURL):**\n    ```bash\n    curl -X POST http://localhost:5000/api/voice \\\n    -H \"Content-Type: application/json\" \\\n    -d '{ \"chats\": [], \"newMessage\": \"नमस्ते अवि, गणेश चतुर्थी के बारे में बताएं।\", \"languageCode\": \"hi-IN\" }' \\\n    --output response.json # Save response to a file\n    # Then parse response.json to extract audioContent and save as .mp3\n    ```\n\n### 4. `/api/gemini-stream`\n-   **Method:** `POST`\n-   **Description:** Streams chunks of text response from the Gemini AI model using Server-Sent Events (SSE). Useful for displaying real-time AI generation on the frontend.\n-   **Request Body (JSON):**\n    ```json\n    {\n      \"chats\": [\n        {\"role\": \"user\", \"content\": \"Tell me a short story about an Indian festival.\"}\n      ],\n      \"newMessage\": \"Make it about Holi.\"\n    }\n    ```\n    - `chats`: (Same as `/api/text`)\n    - `newMessage`: (Same as `/api/text`)\n-   **Success Response (SSE Stream):**\n    ```\n    data: {\"content\": \"Once \"}\n    data: {\"content\": \"upon \"}\n    data: {\"content\": \"a \"}\n    data: {\"content\": \"time...\"}\n    ...\n    ```\n-   **Error Response:**\n    If an error occurs before headers are sent, a JSON error response will be returned (similar to other endpoints). If an error occurs during streaming, an SSE `data` event with an `error` field will be sent, and the connection will be terminated.\n-   **Example (cURL):**\n    ```bash\n    curl -X POST http://localhost:5000/api/gemini-stream \\\n    -H \"Content-Type: application/json\" \\\n    -H \"Accept: text/event-stream\" \\\n    -d '{ \"chats\": [], \"newMessage\": \"How does AI help in preserving ancient Indian languages?\" }'\n    ```\n\n## 🐳 Docker Setup & Deployment\n\nDocker allows you to package the backend application and its dependencies into a container, ensuring it runs consistently across different environments.\n\n1.  **Create `Dockerfile`:**\n    Create a file named `Dockerfile` in the root of your backend project:\n    ```dockerfile\n    # Use an official Node.js runtime as a parent image\n    FROM node:22\n\n    # Set the working directory in the container\n    WORKDIR /app\n\n    # Copy package.json and package-lock.json (if available) to the working directory\n    COPY package*.json ./\n\n    # Install dependencies\n    RUN npm install\n\n    # Copy the rest of the application code to the working directory\n    COPY . .\n\n    # Expose the port the app runs on\n    EXPOSE 5000\n\n    # Command to run the application\n    CMD [\"npm\", \"start\"]\n    ```\n\n2.  **Create `.dockerignore`:**\n    Create a file named `.dockerignore` in the root of your backend project. This prevents unnecessary files from being copied into your Docker image, speeding up builds and reducing image size.\n    ```\n    node_modules\n    .env\n    npm-debug.log\n    Dockerfile\n    .git\n    .gitignore\n    README.md\n    ```\n\n3.  **Build the Docker Image:**\n    Navigate to your backend project's root directory in your terminal and run:\n    ```bash\n    docker build -t avi-cultural-ai-backend .\n    ```\n\n4.  **Run the Docker Container:**\n    You need to pass your environment variables to the container. The most secure way is to use a `.env` file with `docker run --env-file`.\n    **Ensure your `.env` file (the one with actual secrets) is present in the directory where you run this command.**\n\n    ```bash\n    docker run -p 5000:5000 --env-file ./.env avi-cultural-ai-backend\n    ```\n    - `-p 5000:5000`: Maps port 5000 on your host machine to port 5000 inside the container.\n    - `--env-file ./.env`: Tells Docker to load environment variables from your `.env` file. **Make sure this file is present and correctly configured.**\n\n    Your backend should now be running inside a Docker container, accessible via `http://localhost:5000`.\n\n## 🛠️ Built With\n-   **Node.js**\n-   **Express.js**\n-   **Google Gemini API** (`@google/genai`)\n-   **Google Cloud Text-to-Speech** (`@google-cloud/text-to-speech`)\n-   **dotenv** (for environment variable management)\n-   **cors** (for enabling Cross-Origin Resource Sharing)\n-   **Nodemon** (for development auto-restarts)\n\n## 🙏 Acknowledgements:\n-   **Google Cloud:** For providing powerful AI services like Gemini and Text-to-Speech.\n-   **Express.js:** For simplifying API development.\n-   **Google Cloud SDK DOCS:** For helping thoughout the development\n\n## 🏆 Reason To Build:\n-   Figure Out the use case of AI and explore my own capabilities\n-   Built to participate and win BuildIt Hackathon by Bal Bharati Public School, Pitampura.\n\n## 🤝 Contributing\nContributions are welcome!
